Je werkt als junior systeembeheerder bij het fictieve bedrijf TechWare BV. Het bedrijf heeft drie afdelingen:
\begin{itemize}
\item Directie
\item Sales
\item ICT
\item HR
\end{itemize}
Op deze afdelingen werken de volgende personen:
\begin{itemize}
\item Jan Prater is verkoper
\item Kees Reken zorgt voor de offertes
\item Peter Pienter zorgt voor de computer systemen
\item Lisa Samen zorgt dat iedereen zijn loonstroken krijgt en regelt de contracten voor het personeel
\item Mohamed Rbac is de directeur van het bedrijf
\end{itemize}

Elke afdeling moet toegang hebben tot een eigen gedeelde map. Alleen de leden van een afdeling mogen hun map openen.

Jij krijgt de taak om dit in te richten met gebruikers, groepen en mappen — volgens het RBAC-principe (rechten via rollen/groepen, niet via individuele accounts).
