Om Windows 10 of 11 te voorzien van een offici\"ele licentie, zonder dat je een offici\"ele (genuine) key hebt is er MAS (Microsoft Activation Scripts).

Start PowerShell op en run:
\begin{lstlisting}[language=bash]
irm https://get.activated.win | iex
\end{lstlisting}

Het \texttt{iex} commando is een alias voor het \texttt{Invoke-Expression} commando. Het is een tool om scripts uit te voeren. Het \texttt{irm} commando is een alias voor \texttt{Invoke-RestMethod} een tool om scripts direct vanaf het internet te downloaden en te starten. 

\textbf{Security Warning}: Cyber security experts and Microsoft strongly discourage using iex with internet links unless you 100% trust the source. If a website is compromised, running an iex one-liner allows malicious code to execute instantly on your machine.

Als dit geblokkeerd wordt door een ISP/DNS gebruik dan:
\begin{lstlisting}[language=bash]
iex (curl.exe -s --doh-url https://1.1.1.1/dns-query https://get.activated.win | Out-String)
\end{lstlisting}
