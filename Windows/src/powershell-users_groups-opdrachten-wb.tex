Voor deze opdracht maken we gebruik van de commando's in PowerShell

\begin{enumerate}
\item Maak gebruikers aan
    \begin{itemize}
    \item jan\_sales
    \item lisa\_hr
    \item peter\_ict
    \end{itemize}
\item Maak groepen aan
    \begin{itemize}
    \item Sales
    \item HR
    \item ICT
    \end{itemize}
\end{enumerate}

Alle gebruikers van Windows moeten lid zijn van de Users (Gebruikers) groep. Dus voeg alle gebruikers toe aan deze groep.

Plaats nu de gebruikers in hun eigen groep.
