We gaan de bestaande key vervangen door een nieuwe key. Dat kan niet zomaar in Windows. We moeten daarvoor een aantal stappen doorlopen:
\begin{enumerate}
\item Zet WiFi uit en zorg dat er geen netwerkkabel in je systeem zit. Er mag geen netwerk verbinding zijn.
\item Ga naar Settings
\item Ga naar Security \& Privacy
\item Zoek naar Activation Settings
\item Klik op Change bij Change activation key
\item Voer de generic activation key in:
	\begin{itemize}
	\item Voor Pro: VK7JG-NPHTM-C97JM-9MPGT-3V66T
	\item Voor Education: YNMGQ-8RYV3-4PGQ3-C8XTP-7CFBY
	\item Voor Education N: 84NGF-MHBT6-FXBX8-QWJK7-DRR8H
	\end{itemize}
\item Klik Next of Activate Product
\item De PC moet herstarten en de upgrade zal worden uitgevoerd
\item Na de reboot verbind je de PC weer aan het netwerk (WiFi of kabel)
\item Ga wederom naar Settings
\item Ga naar Security \& Privacy
\item Zoek naar Activation Settings
\item Klik op Change bij Change activation key
\item En voer de echte key in
\end{enumerate}
