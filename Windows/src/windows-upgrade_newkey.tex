We gaan de bestaande key vervangen door een nieuwe key. Dat kan niet zomaar in Windows. We moeten daarvoor een aantal stappen doorlopen:
\begin{enumerate}
\item Zet WiFi uit en zorg dat er geen netwerkkabel in je systeem zit. Er mag geen netwerk verbinding zijn!
\item Ga naar Settings
\item Ga naar Security \& Privacy
\item Zoek naar Activation Settings
\item Klik op Change bij Change activation key
\item Voer de generic activation key in voor de versie waarnaar je wilt upgraden:
	\begin{itemize}
	\item Voor Education: YNMGQ-8RYV3-4PGQ3-C8XTP-7CFBY
	\item Een overzicht van Windows 10/11 generic Activation Keys (RTM) zie \'e\'en van de volgende sites:
		\begin{itemize}
		\item \url{https://hypestkey.com/free-windows-10-windows-11-keys/}
		\item \url{https://gist.github.com/vaimalaviya1233/fe64d325408bd69106b6f76e0b57ee4c}
		\end{itemize}
	\end{itemize}
\item Klik: Continue
\item Krijg je de Start knop dan is er nog een netwerkverbinding...
\item Negeer alle error meldingen
\item Boven in je scherm nu wel al staan Windows Education
\item Reboot de PC
\item Connect het Internet
\item Ga wederom naar Settings
\item Ga naar Security \& Privacy
\item Zoek naar Activation Settings
\item Klik op Change bij Change activation key
\item Voer een geldige Activation Key in
\end{enumerate}

Een eenvoudigere methode, maar nog niet getest, lijkt via de commandline te kunnen in 3 stappen (Start PowerShell als Administrator):
\begin{enumerate}
\item We beginnen met de bestaande key weg te gooien:
\begin{lstlisting}[language=bash]
slmgr.vbs /upk
\end{lstlisting}

\item Daarna voegen we de nieuwe key toe:
\begin{lstlisting}[language=bash]
slmgr.vbs /ipk YOUR-PRODUCT-KEY
\end{lstlisting}

\item Tot slot activeren we de nieuwe key:
\begin{lstlisting}[language=bash]
slmgr.vbs /ato
\end{lstlisting}
\end{enumerate}
