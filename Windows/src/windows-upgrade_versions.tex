\begin{description}
\item[Home] Thuis editie. Is een uitgeklede versie van Windows die je bijvoorbeeld niet in een Domein kan hangen. Het heeft geen bedrijfsbeveilings tools en mist remote desktop mogelijkheiden
\item[Pro] De internationale \textquote{volldige} versie voor het bedrijfsleven, heeft 24 maanden ondersteuning per jaarlijkse update (BitLocker full-disk encryption, Remote Desktop, Hyper-V virtual machines, and domain joining.)
\item[Education] De internationale Education, heeft 36 maanden ondersteuning per jaarlijkse update (Built on Enterprise-level security and tools, but with consumer ads and suggested apps turned off by default.)
\item[Enterprise] De internationale \textquote{volldige} versie voor het bedrijfsleven, heeft 26 maanden ondersteuning per jaarlijkse update. (Advanced fleet-wide management, AppLocker, Credential Guard, and volume licensing.)
\end{description}

Versies met een N toegevoegd zijn versies die voldoen aan de regels van de Europese Gemeenschap. Deze versies missen vaak de mediaplayer en de bijbehorende libraries.
