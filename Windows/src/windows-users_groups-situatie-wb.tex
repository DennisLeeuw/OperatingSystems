Je werkt als junior systeembeheerder bij het fictieve bedrijf TechWare BV.
Het bedrijf heeft drie afdelingen:
\begin{itemize}
\item Sales
\item ICT
\item HR
\end{itemize}
Elke afdeling moet toegang hebben tot een eigen gedeelde map. Alleen leden van de juiste afdeling mogen hun map openen.
Jij krijgt de taak om dit in te richten met gebruikers, groepen en mappen — volgens het RBAC-principe (rechten via rollen/groepen, niet via individuele accounts).
