\item Voeg een groep Boekhouding toe door gebruik te maken van het commando:
\begin{lstlisting}[language=bash]
New-LocalGroup
\end{lstlisting}
\item Voeg Cas Calc toe aan de groep Boekhouding. Een nieuwe gebruiker maak je aan met:
\begin{lstlisting}[language=bash]
New-LocalUser
\end{lstlisting}

\begin{lstlisting}[language=bash]
Set-ACL

\begin{lstlisting}[language=bash]
Get-ACL
