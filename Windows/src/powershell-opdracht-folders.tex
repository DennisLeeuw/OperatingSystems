Maak deze directory tree aan in je home-directory:
\begin{verbatim}
Nova College
    |-- Uitprobeer map
    |-- OSWL-Windows
    |     \-- Blok1
    |-- OSWL-Linux
    |     \-- Blok2
    |-- Logica
    |     \-- Blok1
    |-- Frontend
    |     \-- Blok1
    |-- Rekenen
    |     \-- Blok1
    |-- Burgerschap
    |     \-- Blok1
    |-- Nederlands
    |     \-- Blok1
    |-- Engels
    |     \-- Blok1
    \-- SLB
          \-- Blok1
\end{verbatim}
In deze directories kan je je schoolwerk gestructureerd, per vak, opslaan (en weer terug vinden). Je kan de documenten met uitleg in deze mappen opslaan, je gemaakte opdrachten en ook de documentatie die je krijgt in de projectweek.

Maak in elk nieuw blok de benodigde directories aan.
