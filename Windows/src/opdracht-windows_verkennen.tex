Ga naar de Windows directory en voer het volgende commando uit:
\begin{lstlisting}[style=DOS]
PS C:\Windows> dir *.exe
\end{lstlisting}
Je krijgt nu een overzicht van alle executables in de \texttt{\textbackslash Windows} directory.
\begin{enumerate}
\item Welk commando heb je gebruikt om in de Windows directory te komen?
\item Wat doet het \texttt{dir} commando?
\item Voeg de naam van elk commando en een beschrijving van de werking aan je document toe. Sla het document op.
\end{enumerate}
