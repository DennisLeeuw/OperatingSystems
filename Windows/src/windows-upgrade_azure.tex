
We gaan gebruik maken van de Azure for Education site om ons Windows Home systeem te upgraden naar Education. Hiervoor moeten we naar de Azure Portal \url{https://portal.azure.com/#view/Microsoft_Azure_Education/EducationMenuBlade/~/software}. Na het volgen van de link kom je op een pagina terecht met ongeveer deze tekst:

\begin{minipage}[t]{\linewidth}
\raggedright
\adjustbox{valign=t}{%
	\includegraphics[width=0.99\linewidth]{Azure-Account_registratie.png}%
}
\end{minipage}

\begin{enumerate}
\item Klik op de registreren link
\item Vul je gegevens in (zover als je die met Microsoft wilt delen)
\item Selecteer Windows 11 Education
\item Selecteer View Key (NIET downloaden)
\item Maak een kopie van de Key
\end{enumerate}
