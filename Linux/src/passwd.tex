Met \texttt{passwd}\index{passwd} kunnen we het wachtwoord van een gebruiker aanpassen. Zonder extra informatie passen we ons eigen wachtwoord aan:
\begin{lstlisting}[language=bash]
$ passwd
\end{lstlisting}

Als root kunnen we ook de het wachtwoord van een andere gebruiker aanpassen:
\begin{lstlisting}[language=bash]
$ sudo passwd eengebruiker
\end{lstlisting}
