Met IaC (Infrastructure as Code) beheer en configureer je een IT-infrastructuur. Dit gebeurt door code in plaats van handmatige processen. Je beschrijft waaraan bijvoorbeeld een server moet voldoen: welke software ge\"installeerd moet zijn, welke configuratie bestanden aanwezig moeten zijn en welke settings daarin moeten staan.

In de open source wereld zijn bekende tools in willekeurige volgorde:
\begin{itemize}
\item Ansible - \url{https://www.redhat.com/en/ansible-collaborative}
\item Terraform - \url{https://developer.hashicorp.com/terraform}
\item Puppet - \url{https://www.puppet.com}
\item Chef - \url{https://www.chef.io}
\item Salt - \url{https://saltproject.io}
\end{itemize}
