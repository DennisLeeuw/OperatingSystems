Netfilter\index{netfilter} is de kernel technologie voor het filteren van netwerkverkeer. Dit filter kan werken op de verschillende netwerklagen. Het kan acties ondernemen op ARP verkeer, op ethernet verkeer, op IP en op TCP niveau, maar ook op applicatie level. Kortom dit is heel complexe materie en om deze comlexiteit iets simpeler te maken is er UFW de Uncomplicated FireWall.
