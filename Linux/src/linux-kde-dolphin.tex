Gebruik Dolphin om je bestanden te organiseren.
\begin{enumerate}
\item Open je persoonlijke map.
\item Maak een map met de naam \texttt{Linux\_Lessen}
\item Maak daarin de volgende submappen:
	\begin{itemize}
        \item GUI
        \item Introductie
        \item Bestanden\_en\_mappen
	\end{itemize}
\item Bekijk de eigenschappen van de map Linux\_Lessen.
\item Noteer waar je persoonlijke map zich bevindt.
\item Controleer of je de drie submappen kunt terugvinden.
\item Verplaats het bestand \texttt{KDE\_Verkennen} naar de map GUI.
\end{enumerate}

Beantwoord de vragen:
\begin{enumerate}
\item Wat is een persoonlijke map in Linux?
\item Wat is het voordeel van het werken met submappen?
\item Welke informatie kun je vinden bij de eigenschappen van een map?
\end{enumerate}

Zet de antwoorden op de vragen in een nieuw document en sla dit op in de \texttt{GUI} map met als bestandsnaam \texttt{Mappen}.
